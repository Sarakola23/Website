About the project

Trolley

Fully working Apple Store application

Trolley is a sharable grocery list application that allows users to create and share grocery lists with friends and family.

It integrates Supabase for authentication, user preferences, and saved lists.

Worked on

● Built a React Native + TypeScript mobile app with Expo Router for navigation.

● Designed a real-time notification system using Supabase Postgres triggers and channels, including grouped activity (e.g. "Darren added 4 items").

● Implemented household invites, item assignment, and swipe-to-delete list interactions.

Built with

React Native TypeScript Supabase Expo Router
