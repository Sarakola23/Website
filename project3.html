About the project

Moodroll

Fully working Web App

Moodroll is a mood-based movie discovery platform that helps users find films based on how they feel rather than traditional genres or search.

It integrates TMDB API for movie data and Supabase for authentication, user preferences, and saved lists.

Worked on

● Built responsive React + TypeScript UI with dynamic mood filtering system.

● Integrated TMDB API for real-time movie data fetching and search.

● Implemented Supabase backend for authentication and persistent user data.

Built with

React TypeScript Supabase TMDB API
